<objective>
Retire the GL-surface lifecycle risk (ROADMAP success criterion #4, D-04), then close the phase with the final AND-00 and AND-02 gates and the human confirmation D-04 requires.

Background:
- Locking the screen and pressing Home destroy the NativeActivity's ANativeWindow, so egui_glow must rebuild its EGL surface on Resumed. This is the code path emilk/egui PR #3867 fixed for glow. 01-01 already proved #3867 is an ancestor of the pinned crmne/egui ba6790fe, as D-06 requires.
- Rotation does not recreate the activity, because cargo-apk's default config_changes is "orientation|keyboardHidden|screenSize". The window is resized instead, so the PID must stay the same through rotation.

Purpose: before any later phase builds UI on this stack, prove the pinned fork actually survives Android's lifecycle at runtime, not just that it contains the fix.
Output: scripts/android-lifecycle-check.sh, its PASS log, final gate results, and the human sign-off.
</objective>
